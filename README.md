# Building WRLDWIDE

Solo founder-operator. Building owned products, content systems, and AI-driven operations since late 2025.

## What I build
- **ChinaMaxxing** (chinamaxxing.io): a live, production content and travel-intelligence platform. Next.js, Supabase, self-hosted on a VPS.
- **Basecamp dashboard**: an operations console for running projects and agents.
- **WRLDWIDE Clips**: a short-form video pipeline.
- **WRLDWIDE Homes**: a land and property sourcing engine.
- **Manufactured Hype**: a content and distribution service.

## Stack
TypeScript, Next.js, React, Node, Python, Supabase, PostgreSQL, Docker, PM2, n8n, Traefik.

## How I work
Local Mac for building, GitHub for source, VPS for running live. Agents handle research, code, and operations under a single shared memory.

Most of my work is in private repositories. Ask for a walkthrough of any project.
